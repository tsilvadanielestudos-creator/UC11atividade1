# Sistema de Leilões

## Sobre o projeto

Sistema desktop desenvolvido para informatizar as rotinas de uma casa de leilões. O projeto está em fase inicial de implementação e, neste momento, permite o cadastro e a listagem dos produtos que serão leiloados, com os dados armazenados em um banco de dados relacional.

Este repositório foi criado para manter o projeto versionado com Git e GitHub, atendendo às práticas de segurança e de qualidade de software adotadas pela empresa.

## Funcionalidades

- Cadastro de produtos para leilão
- Listagem dos produtos cadastrados

## Tecnologias utilizadas

- **Java** — linguagem de programação da aplicação
- **Java Swing** — interface gráfica
- **MySQL** — sistema de gerenciamento de banco de dados
- **JDBC (MySQL Connector/J)** — conexão entre a aplicação e o banco
- **NetBeans IDE** — ambiente de desenvolvimento
- **Git e GitHub** — versionamento do código

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/tsilvadanielestudos-creator/UC11atividade1.git
   ```
2. Importe o script do banco de dados no seu SGBD (MySQL).
3. Abra o projeto no NetBeans.
4. Ajuste o usuário e a senha do banco na classe de conexão, se necessário.
5. Execute o projeto.
